# 异步事件路由 AOS

F175 的 SVD 和驱动均无 AOS；其余 26 个 LL 系列有 AOS。LL 的 SVD 无独立 PCA、
PCNT 或 EAU 外设。F175 的 GTIM/LPTIM 归[定时器组](timer-gen.md)。

| 版本 | 系列 | SVD 顶层寄存器数 |
|---|---|---:|
| `aos_v1` | F115 | 5 |
| `aos_v1_1` | F120 | 5 |
| `aos_v1_2` | F155 | 7 |
| `aos_v3` | M120 | 11 |
| `aos_v4` | M458 | 12 |
| `aos_v5` | F431/M413 | 16 |
| `aos_v6` | K116/K118 | 46 |
| `aos_v7` | A460/F451/F452/F460 | 57 |
| `aos_v8` | F334/F336 | 63 |
| `aos_v9a` | F467/A4A0/F4A0/F4A2 | 74 |
| `aos_v9b` | A472/F472 | 74 |
| `aos_v10` | A448/F448/M441 | 87 |
| `aos_v11` | A4A8/F4A8 | 94 |

M0+ AOS 的基址为 0x40000C00，M4 为 0x40010800。13 组布局按寄存器名、偏移和位域分出。F115 和 F120 的五个寄存器偏移和位区间一致，
F155 沿用这五处位置并增加两个 DMA 触发选择寄存器。

AOS 的主编号按路由功能和目标规模排序。同族的命名变体和 DMA 扩展保留 `v1` 主编号。
`aos_v9a` 和 `aos_v9b` 的 74 个寄存器对应不同的路由目标。事件号从设备头的 `EVT_SRC_*` 提取，目标选择从
`hc32_ll_aos.h` 提取。M458 的目标宏包含两个 DMA 通道及六个 ADC 目标。

F431/M413/M458 的 `FCG0_PERIPH_AOS` 映射到 `CMU_FCG_AOS`，其他 M4 系列映射到
`PWC_FCG0_AOS`。
