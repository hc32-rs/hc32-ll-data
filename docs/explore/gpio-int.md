# GPIO、调试与中断

## GPIO 与调试

| 版本 | 系列 | 布局 |
|---|---|---|
| `gpio_v4` | F175 | AFR 选择，GPIO@0x40020000 |
| `gpio_v5` | F115/F120/F155/M120 | 字节端口，0x500 区的保护/控制寄存器 |
| `gpio_v6` | K116/K118 | 32 位分块端口，PCR/PFSR 成对 |
| `gpio_v7` | M4 的 18 个系列 | 16 位交错端口，PCR/PFSR 成对，0x3F4 区的保护/控制寄存器 |
| `gpio_v8` | F431/M413 | 字节端口，0x300 区的保护/控制寄存器 |

F175 还含 `exti_v1` 和 `dbg_v3`。其他 M0+ 系列的 DBGC 归 `dbg_v2`；
F155/M120、K116/K118 的额外 DBGC_T 分为 `dbgt_v1/v2`。M4 的 DBGC 在
0xE0042000，`dbg_v4` 为共同分类建议，FMC、CHIPID 和 MCUSTPCTL2 等寄存器按实例核对。
GPIO 复用用 `hc32_ll_gpio.h` 的 `GPIO_FUNC_*` 及 SDK 例程核对，封装级完整映射依赖芯片资料。

## IRQ 向量

| 系列 | 设备头 `IRQn_Type` |
|---|---|
| F115/F120/F155/M120 | 外部中断占前 8 个槽，通用槽为 `INT008_IRQn..INT031_IRQn` |
| K116/K118 | 具名固定向量，多个外设或端口可共享同一向量 |
| F175 | 具名固定向量，如 `DMAC_IRQn=7` |
| A460/F451/F452/F460/F467/A4A0/A4A8/F4A0/F4A2/F4A8 | 144 个通用槽 `INT000_IRQn..INT143_IRQn` |
| A448/A472/F334/F336/F448/F472/M441/F431/M413 | 0–15 通用槽，16–31 为具名外部端口中断，其后为具名外设向量 |
| M458 | 固定具名向量，前 8 个为外部端口中断 |

INTC 的 M0+ 候选分组为 `intc_v1`（F115/F120/M120）、`intc_v2`（F155）、
`intc_v3`（K116/K118）。M4 可先按路由模式区分，匿名槽系列的 SVD 有 170–171 个顶层寄存器，
混合式系列有 51–58 个，M458 有 18 个。三类需要分别描述实际寄存器，IRQn 以设备头为准，
SVD 的中断节点覆盖情况见[总览](../svd-overview.md)。

事件端口由 AOS 承载：K116/K118 和有 `hc32_ll_event_port.h` 的 17 个 M4 系列为
`event_port_v1` 候选；M120 的 EVPRT 块为 `event_port_v2`。
