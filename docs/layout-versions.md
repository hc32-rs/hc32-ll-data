# 布局编号与功能档位

对已比较功能差异的外设，`v1` 表示基础档，主编号越大表示更多功能或更完整的控制能力。
同一布局的扩展、裁剪和命名变体沿用主编号，使用 `_1`、`_2` 等后缀。
同档但无明确衍生关系的布局可用 `a`、`b` 区分。编号本身不保证寄存器兼容，也不表示发布先后。
跨系列比较使用展开 `derivedFrom` 后的寄存器和位域，并结合 SDK 的定义。
未排档的分组继续使用旧布局 ID。与 DDL 共用的档位保留相同编号，LL 中可以从较高档开始出现。

| 外设 | 当前档位 | 功能依据 |
|---|---|---|
| [ADC](explore/analog.md) | `adc_v5a`、`adc_v9`、`adc_v10` | F175 是与 DDL `adc_v5` 可比的旧序列分支，输入能力不同且没有内嵌 BGR。M0+ 的新布局为 SeqA/SeqB，M4 扩展采样、同步、增益等控制，具体功能按实例登记。 |
| [DMA](explore/dma.md) | `dma_v3`–`dma_v6_2` | F175 为旧 CONF/CONFA 档。M0+ 的 `v4_1` 在 `v4` 基础上增加 LLP。M4 的 `v6_1` 加 CHENCLR，`v6_2` 再加 HPROT，控制器数、通道数和掩码按系列记录。 |
| [AOS](explore/pca-bt-pcnt-aos.md) | `aos_v1`–`aos_v11` | 基础路由起步，按 DMA、事件端口和可配置路由目标的规模分档。F120 为 F115 的命名变体 `v1_1`，F155 增加两个 DMA 目标，记作 `v1_2`。两个 74 寄存器组同档，目标阵容不同。 |
| [SWDT](explore/power-wdt.md) | `swdt_v1` → `swdt_v1_1` | 基础 SR/RR 由 ICG 配置 → 增加可直接配置的 CR。 |
| [SPI](explore/spi-i2c-i2s.md) | F175 为 `spi_v2` | 与 DDL 的 CR0/CR1 独立布局档统一编号，其余 LL SPI 仍用已有布局 ID。 |

## 旧 ID 对照

| 外设 | 上次功能排序的编号 → 当前 |
|---|---|
| DMA | `v5→v4_1`、`v7→v6_1`、`v8→v6_2` |
| AOS | `v1a→v1_1`、`v2→v1_2` |
| SWDT | `v2→v1_1` |
| SPI | `v3→v2` |
